# Neovim ショートカット

## 🔍 検索（Leader + S）

| ショートカット | 説明 |
|----------|-------------|
| `<leader>sf` | ファイルを検索 |
| `<leader>sk` | キーマップを検索 |
| `<leader>sh` | ヘルプを検索 |
| `<leader>ss` | Telescope ピッカーを選択 |
| `<leader>sw` | 現在のカーソル下の単語を検索 |
| `<leader>sg` | テキストを grep で検索（ライブグレップ） |
| `<leader>sd` | 診断内容を検索 |
| `<leader>sr` | 前回の検索を再開 |
| `<leader>s.` | 最近開いたファイルを検索 |
| `<leader>s/` | 開いているファイルの中から検索 |
| `<leader>sn` | Neovim 設定ファイルを検索 |

## 📝 バッファ検索

| ショートカット | 説明 |
|----------|-------------|
| `<leader>/` | 現在のバッファ内であいまい検索 |
| `<leader><leader>` | 開いているバッファを検索 |

## 🗂️ ナビゲーション

| ショートカット | 説明 |
|----------|-------------|
| `<C-h>` | 左のウィンドウにフォーカス移動 |
| `<C-l>` | 右のウィンドウにフォーカス移動 |
| `<C-j>` | 下のウィンドウにフォーカス移動 |
| `<C-k>` | 上のウィンドウにフォーカス移動 |

## ⚡ Hop ナビゲーション

| ショートカット | 説明 |
|----------|-------------|
| `s` | 1文字目に Hop |
| `S` | 2文字目に Hop |
| `f` | 単語に Hop |
| `F` | 行に Hop |

## 🔧 コード操作

| ショートカット | 説明 |
|----------|-------------|
| `<leader>f` | バッファをフォーマット |
| `<leader>ca` | コードアクション |
| `<leader>rn` | 変数をリネーム |
| `<leader>D` | 型定義を表示 |
| `<leader>ds` | ドキュメント内のシンボルを表示 |
| `<leader>ws` | ワークスペース内のシンボルを表示 |
| `<leader>th` | インレイヒントの表示切り替え |

## 🚨 診断情報

| ショートカット | 説明 |
|----------|-------------|
| `[d` | 前の診断メッセージに移動 |
| `]d` | 次の診断メッセージに移動 |
| `<leader>e` | 診断エラーメッセージを表示 |
| `<leader>q` | 診断クイックフィックスリストを開く |

## 📦 バッファ管理

| ショートカット | 説明 |
|----------|-------------|
| `<S-l>` | 次のバッファに切り替え |
| `<S-h>` | 前のバッファに切り替え |
| `<leader>bch` | 左側のバッファを閉じる |
| `<leader>bcl` | 右側のバッファを閉じる |
| `<leader>bco` | 他のバッファを全て閉じる |

## 📂 ファイル管理

| ショートカット | 説明 |
|----------|-------------|
| `\` | ファイルツリーを表示/隠す |

## ℹ️ ヘルプ・情報

| ショートカット | 説明 |
|----------|-------------|
| `<leader>?` | チートシートを開く |
| `K` | ホバードキュメント表示 |
| `gd` | 定義に移動 |
| `gr` | 参照を検索 |
| `gI` | 実装に移動 |
| `gD` | 宣言に移動 |

## ✏️ インサートモードのナビゲーション

| ショートカット | 説明 |
|----------|-------------|
| `jj` | ノーマルモードに戻る |
| `<C-h>` | カーソルを左に移動 |
| `<C-l>` | カーソルを右に移動 |
| `<C-j>` | カーソルを下に移動 |
| `<C-k>` | カーソルを上に移動 |

## 🎨 テキスト操作

| ショートカット | 説明 |
|----------|-------------|
| `gc` | 行・ブロックをコメント化 |
| `va)` | かっこの周囲を選択（mini.ai） |
| `yinq` | 次のシングルクォート内をコピー（mini.ai） |
| `ci'` | シングルクォート内を変更（mini.ai） |
| `saiw)` | 単語の周囲にかっこを追加（mini.surround） |
| `sd'` | シングルクォートを削除（mini.surround） |
| `sr)'` | かっこを置き換え（mini.surround） |
